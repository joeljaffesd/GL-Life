GL-Life Stroke Drawing Test

How to use:

  1. Check the "Draw Mode" checkbox to enable drawing
  2. Adjust the stroke width using the slider (5-50)
  3. Select a color from the 6 color buttons (matches particle types)
  4. Click and drag on the canvas to draw strokes
  5. Watch how particles react to your drawn strokes!
  6. Use "Clear Strokes" to remove all drawn strokes

Note: Drawn strokes act as virtual particles of the selected type and influence the particle simulation according to the same rules that govern particle-to-particle interactions.
